# Zaptech Australia website

Static, responsive website built from the approved charcoal-and-mint design. No build step or external dependencies are required. Serve `index.html` with `styles.css`, `script.js` and `favicon.svg` beside it.

## Contact

- Phone: 03 4150 7515 (`tel:+61341507515`).
- Email: contact@zaptech.com.au.
- Contact enquiries open a prepared message in the visitor's email application. The visitor must send the email there. This website does not submit, store or email form data through a server and does not claim a message has been delivered. A future direct-submission form requires a configured backend or form provider.
- Clicking a service selects it in the contact form.

## Hosting

The repository was already associated with `https://website-zaptech1.vercel.app` when this version was prepared. Repository homepage metadata does not confirm an active Vercel deployment or automatic deployment settings. GitHub Pages was disabled at the start of the task. No custom domain or DNS changes are included in this commit.

The files work at the domain root or in a GitHub Pages repository subdirectory because asset paths are relative. Existing unrelated repository files are preserved.

## Brand and content

Name: Zaptech Australia. Headline: “Get cracking. Keep growing.” Supporting line: “Practical technology, built around your business.” Audience: Australian small and medium businesses.

The ZA mark is recreated as scalable vector geometry from the supplied logo, preserving its angular silhouette and recolouring it mint. The large hero treatment uses the same shape as an outline.
